**Ventoy EFI Tool – Create a Bootable Ventoy USB Without Booting into an Operating System**

Ventoy EFI Tool allows users to create a Ventoy bootable USB drive directly from the EFI environment, without needing to boot into Windows, Linux, or another operating system.



This is the fork of Ventoy: https://github.com/ventoy

All the credits goes to original developers.



This [VentoyEFI](https://github.com/satkush2222/ventoyEFI/tree/EFI) is the patched version of [ventoy-1.1.18-livecd.iso](https://sourceforge.net/projects/ventoy/files/v1.1.18) in order to run this direct from EFI partition of disk.







###### Important note: **Target EFI partitions  must have at least 200 MB space to work this correctly.**
