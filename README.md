**Ventoy EFI Tool – Create a Bootable Ventoy USB Without Booting into an Operating System**

Ventoy EFI Tool allows users to create a Ventoy bootable USB drive directly from the EFI environment, without needing to boot into Windows, Linux, or another operating system.

The goal of this tool is to provide a simple and convenient way to prepare a Ventoy USB drive at the pre-boot level, making it useful for system recovery, OS installation, and situations where an installed operating system is unavailable.

**Key Features**
- Create a Ventoy bootable USB directly from the EFI environment.
- No need to boot into an installed operating system.
- Designed for pre-boot USB preparation and system maintenance.
- Useful for OS installation, troubleshooting, and recovery workflows.

**Note:** Actual functionality depends on the tool's implementation, firmware compatibility, and supported storage devices. Creating a Ventoy disk may involve partitioning and formatting, which can erase existing data on the target drive.

**Project Goal:** Make Ventoy USB creation possible directly from EFI, with minimal dependency on a running operating system.
